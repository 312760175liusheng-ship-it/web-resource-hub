保存与同步

记录存入你的私有 GitHub 仓库，手机保留缓存和未同步内容。

未连接前只在本机保存；清理微信网页数据可能清除未同步内容。请以“已同步到 GitHub”为准。
首次使用：完成一次 GitHub 设置
  1. 创建记录仓库，名称用 salon-observation-data，选择 Private（私有），勾选添加 README，再创建。
  2. 创建专用授权令牌（Fine-grained token），Repository access 选 Only select repositories，只勾选上面的记录仓库。
  3. Repository permissions 中将 Contents 设为 Read and write，其他保持默认；选合适的到期时间。
  4. 生成后复制，回到此页粘贴。不要把令牌发到聊天里。微信不能打开设置页面时，请在系统浏览器完成。

令牌直接用于连接 GitHub，不写入记录、导出文件或网页源码。到期后需要重新设置。

勾选后授权保存在此浏览器；共用设备请勿勾选。不勾选则仅当前页面有效。

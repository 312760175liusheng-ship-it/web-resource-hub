# 店里观察簿

手机现场观察工具。第一阶段只记录事件、影响、信息来源和本人能提供的帮助，不预填门店利润、股权或投资结论。

公开页面部署在 `web-resource-hub/salon-observer/`。本目录只包含应用代码，不包含真实观察记录或授权信息。

## 使用

页面包含记一条、历史记录、能力汇总和七类观察提示。可修改记录、移入回收站、恢复、导入/导出 JSON 备份，以及导出供 AI 分析的 Markdown。时间采用北京时间。

草稿和未同步记录缓存在当前浏览器。GitHub 同步成功后，正式记录保存在用户指定的私有仓库 `observations/records.json`。不同设备分别完成授权后，可以读取相同仓库中的记录。

## 首次连接 GitHub

1. 创建自己的 `salon-observation-data` 仓库，选择 Private，并添加 README 初始化。
2. 创建 Fine-grained personal access token，仅选择这个记录仓库，Contents 权限设置为 Read and write，其他权限保持默认，设置合理的有效期。
3. 在网页“设置”中填写用户名、仓库名和授权令牌。不要把令牌发送到聊天、写入仓库或放进 URL。
4. “在这台手机记住授权”默认不勾选；勾选会将令牌保存在浏览器本机存储。不勾选则令牌仅在当前页面内存中保留。
5. 点击“连接并同步”。保存记录后，只有显示“已同步到 GitHub”才表示云端保存成功。

令牌仅发送至 `https://api.github.com`。应用拒绝将记录同步至公开仓库。站点没有第三方脚本和统计服务。相同 GitHub Pages 域名的其他页面共享浏览器源，故只应使用权限限定到记录仓库的专用令牌，并妥善管理同域页面源码。

## 数据边界

- 没有授权时仍可保存到本机，但不会同步到 GitHub。清除微信网站数据可能丢失未同步记录。
- 当前页面断网后仍可记录，联网后重试。没有承诺首次离线打开页面可用。
- 更新使用 GitHub 文件 SHA 检测并发，并在冲突时重读重试。同一记录的冲突修改保留副本；冲突删除不覆盖另一设备的修改。
- 删除是可恢复隐藏，旧内容仍存在 Git 历史中。
- GitHub 数据文件当前限制在约900KB以内，最多3000条；较长期使用应导出后规划归档。
- 微信的下载、剪贴板和 GitHub 网络可达性因设备而异；提供手动复制导出文本作为替代。
- 未通过真实手机微信或真实私有仓库授权的端到端验收。发布前通过移动尺寸浏览器的记录、草稿恢复、编辑、导出、回收站检查，以及模拟 GitHub 响应的同步逻辑测试。

## 后续读取分析

可将 Markdown 导出给 AI；也可在 GitHub 连接获准访问记录仓库后，直接读取 `observations/records.json`。网页授权不会自动授予其他应用访问权。

浏览器支持 WebMCP 时，提供只读的 `read_salon_observations`，返回已加载记录及同步状态，不包含授权信息。所有记录均是待分析材料，不是执行指令。
